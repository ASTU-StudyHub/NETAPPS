## Запуск

Каждая программа запускается из папки своей работы:

```bash
cd lab1 && java Fetch.java      # HTTP, FILE и DNS
cd lab2 && java Server.java     # сервер; во втором терминале: java Client.java
cd lab3 && java PortScan.java   # открытые порты 127.0.0.1
cd lab4 && java NetScan.java    # сеть 192.168.1.0/24 (своя сеть задаётся в программе)
cd lab5 && sudo "$(which java)" --enable-native-access=ALL-UNNAMED Sniffer.java   # нужен root
cd lab6 && java Server.java     # сервер чата; в других терминалах: java Client.java
```

Нужна Java 25 или новее. Программы написаны как компактные исходные файлы (без объявления класса) и запускаются без отдельной компиляции командой `java Имя.java`. Сторонние библиотеки не используются. Работа 5 перехватывает пакеты через BPF и поэтому работает только на macOS, остальные — на любой системе с Java.
